# ADR-001: CATS-Net + 大脑架构战略（2026-09-01）

## 状态
已采用 (Accepted) · 2026-09-01 老板拍板

## 背景
GINA 是 Berry.Su 独立项目（9-31 老板明确纠正：GINA ≠ 白龙马续作）。在 9-01 之前，GINA 的开发顺序是分散功能堆砌，没有明确的"大脑本体"。

## 决策
**最高优先级：先把 GINA 的 CATS-Net + 类人脑架构完整，这是 GINA 的核心，是超越所有顶级 agent 的关键。**

- 顺序：CATS-Net + 大脑架构 > UI/商城/3D 桌宠/融资 demo 素材
- CATS-Net 不是某个功能，是**大脑本体**——所有 8 大层都通过它整合
- 在大脑完整之前，UI/商城/3D 桌宠/融资 demo 素材都靠后排
- 这条推翻之前"先做 JARVIS 差距"和"先做 demo v0"的默认排序
