### 2. Hummer Agent（Bitmovin 黑客松作品）
- Slack-native AI agent，只在公开频道运行
- 核心理念：**公开思考透明度**——把推理过程亮出来，让用户随时纠偏
- 跨会话学习，不因会话结束丢失上下文

### 3. Hermes Agent（Nous Research 2026.02 开源）
- 核心机制：**SKILL.md 自动技能创建闭环**
- 每解决一个复杂问题 → 自动生成 SKILL.md → 存技能库 → 下次复用 → 使用中自我改进
- 40+ 内置工具、20+ 平台网关、并行子代理、cron 定时任务
- 社区共享平台：agentskills.io

### 4. SKILL.md 格式规范
```
技能目录/
├── SKILL.md          # YAML头部 + Prerequisites + 编号步骤 + 双路径命令
├── references/       # 补充参考文档
└── templates/        # 可复用模板
```
- YAML 头部：name / description / version / author / license / platforms / metadata
- 正文：Prerequisites → 编号步骤，每步有具体命令代码块
- 关键特征：双路径（有 CLI 工具用工具，没有则退到底层命令）

## 今天复刻的能力

### SKILL.md 自动生成引擎

**新增模块：** `src/memory/skill-generator.js`

**做了什么：**
1. 新建 skill-generator.js 核心引擎
   - 接收成功反思记录 → 自动提取步骤 → 生成 Hermes 格式 SKILL.md
   - 自动创建技能目录（含 references/ 和 templates/）
   - 去重保护（已存在同名技能则跳过）
   - 自动从笔记中提取命令、命令说明、先决条件

2. 在 reflection-executor.js 加触发点
   - 每次成功反思且笔记 > 30 字时自动调用 skill-generator
   - 生成失败不影响反思流程

3. 冒烟测试：37/37 全绿
   - 格式完整性、空参数安全、去重、端到端生成、步骤提取、名称清理、目录结构

**设计原则：**
- self-learning.js（九方向五条线课程表）未动，继续并行运行
- 复刻 = 添加新能力，不是替换旧能力
- 两条线独立演进，互不干扰
